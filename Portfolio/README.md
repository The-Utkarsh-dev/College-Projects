# Personal Portfolio Website

My personal portfolio built with HTML, CSS and JavaScript as part of my Web Development assignment.

## Sections
Home, About Me, Education, Skills, Projects and Contact.

## Features
- Sticky navigation menu linking all sections
- Responsive layout for mobile, tablet and desktop
- Dark / light mode toggle
- Contact form with JavaScript validation
- Time-based greeting and back-to-top button

## How to run
Download or clone the repository and open `index.html` in a browser.
